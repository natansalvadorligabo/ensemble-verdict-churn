# Dataset attribution

`ecommerce_customer_churn.csv` is a normalized CSV derivative of [E-Commerce Customer Churn Analysis and Prediction](https://www.kaggle.com/datasets/ankitverma2010/ecommerce-customer-churn-analysis-and-prediction) by Ankit Verma, version 1, source file `E Commerce Dataset.xlsx`, sheet `E Comm`.

The source dataset is licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This derivative converts the original worksheet to CSV and normalizes categorical values. It is provided solely for academic study and non-commercial demonstration under the same license.
